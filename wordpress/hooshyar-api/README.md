# افزونه وردپرس «هوشیار API» — hooshyar/v1

این افزونه، اندپوینت‌های REST اختصاصی `hooshyar/v1` را برای قالب فرانت‌اند هوشیار پاری‌نگر می‌سازد.

شما «hooshyar/v1 نداشتید» — اینجا کامل ساخته شده است. ✅

---

## 🚀 نصب (۳ دقیقه)

1. پوشه `hooshyar-api` را در `wp-content/plugins/` وردپرس خود آپلود کنید.
2. از پیشخوان وردپرس → **افزونه‌ها**، افزونه «هوشیار API» را **فعال** کنید
   (جدول‌های لازم بلافاصله ساخته می‌شوند).
3. تنظیمات را ست کنید:
   - محتوای `config.sample.php` را کپی کرده و مقادیر (پیامک، بله، درگاه) را وارد `wp-config.php` کنید، **یا**
   - فایل را با نام دلخواه در `wp-content/mu-plugins/` قرار دهید.
4. یک بار **«تنظیمات → پیوندهای یکتا»** را ذخیره کنید تا REST فلاش شود.
5. تست: `https://SITE.com/wp-json/hooshyar/v1/services` را در مرورگر باز کنید — باید `[]` برگردد.

## 📋 پیش‌نیازها (افزونه‌های دیگر)

| نیاز | برای | الزامی؟ |
|---|---|---|
| **JWT Authentication for WP REST API** | صدور توکن ورود | بله (برای لاگین OTP) |
| **WooCommerce** | فروشگاه | بله (برای فروشگاه) |
| **Gravity Forms** + **Gravity Forms REST API** | فرم‌ها | در صورت استفاده از فرم‌ها |
| **CMB2** | ورود آسان خدمات/تیم/پروژه | اختیاری (بدون آن از پست‌تایپ‌ها می‌خواند) |

> برای احراز هویت با JWT، در wp-config.php بگذارید:
> ```php
> define( 'JWT_AUTH_SECRET_KEY', 'کلید-مخفی-خودتان' );
> define( 'JWT_AUTH_CORS_ENABLE', true );
> ```

## 🔌 اندپوینت‌ها

### احراز هویت
| متد | مسیر | توضیح |
|---|---|---|
| POST | `/auth/otp` | ارسال کد یک‌بارمصرف به موبایل |
| POST | `/auth/verify` | تأیید کد + دریافت توکن JWT |
| POST | `/auth/register` | ثبت‌نام با موبایل |
| GET | `/me` | اطلاعات کاربر جاری (**نیاز به توکن**) |

### پشتیبانی
| متد | مسیر | توضیح |
|---|---|---|
| GET/POST | `/support/tickets` | فهرست/ثبت تیکت |
| GET | `/support/tickets/{id}` | جزئیات تیکت |
| POST | `/support/tickets/{id}/reply` | پاسخ به تیکت |

### فاکتور و پرداخت
| متد | مسیر | توضیح |
|---|---|---|
| GET | `/invoices` | فهرست فاکتورهای کاربر |
| GET | `/invoices/{id}` | جزئیات فاکتور |
| POST | `/invoices/{id}/pay` | شروع پرداخت (body: gateway) |
| POST | `/invoices/{id}/pay/verify` | تأیید پرداخت |
| GET | `/invoices/{id}/pdf` | دانلود فاکتور (HTML قابل چاپ) |
| GET | `/invoices/pay/callback` | برگشت از درگاه |

### رویدادها (اعلان فوری مدیر)
| متد | مسیر | توضیح |
|---|---|---|
| GET | `/events` | رویدادهای اخیر (فقط مدیر/پشتیبان) |
| POST | `/events` | ثبت رویداد + ارسال به بله |

### محتوا (خدمات/تیم/پروژه/نظرات/سوالات)
| متد | مسیر |
|---|---|
| GET | `/services` |
| GET | `/team` |
| GET | `/projects` |
| GET | `/testimonials` |
| GET | `/faqs` |

این اندپوینت‌ها از **CMB2 (صفحه تنظیمات)** یا در نبود آن از **پست‌تایپ `hy_service`, `hy_team`, ...** می‌خوانند.

## 🔐 نقش‌ها و دسترسی

- کاربر عادی: فقط تیکت‌ها/فاکتورهای خودش را می‌بیند.
- **مدیر/پشتیبان** (نقش با قابلیت `manage_options` یا `edit_users`): همه تیکت‌ها و فاکتورها + رویدادها.
- ورود OTP: کاربر با شماره موبایل ساخته/یافت می‌شود (متا `hooshyar_mobile`).

## 🛡 ضد اسپم و امنیت

- کد OTP: ۵ رقم، اعتبار ۳ دقیقه، **۵ تلاش ناموفق → قفل**.
- مقایسه کد با `hash_equals` (مقاوم به time-attack).
- محدودیت آستانه تا ۵ بار تلاش در هر درخواست تأیید.
- جدول‌های اختصاصی با `dbDelta` و پشتیبانی `collate` فارسی.

## 📱 پیامک و بله

- **ملی‌پیامک**، **sms.ir** و **ippanel.co** پیاده‌سازی شده‌اند (تنظیم با `HYP_SMS_PROVIDER`).
- **ربات بله**: هشدار تیکت جدید/پرداخت/رویداد فوری به مدیر ارسال می‌شود.

## 💳 درگاه‌ها

- **آیدی‌پی** و **زرین‌پال** (کامل: request + verify + callback)
- **نوین‌پی** و **آقای پرداخت** (اسکلت؛ آدرس startpay تولید می‌شود، verify را طبق مستندات جاری پر کنید)

---

### ⚠️ مواردی که باید بعد از دریافت کلیدهای رسمی تکمیل شود
1. آدرس دقیق verify نوین‌پی/آقای پرداخت (مستندات درگاه در زمان شما ممکن است به‌روز شده باشد).
2. SSL اجباری روی دامنه برای callback درگاه‌ها.
