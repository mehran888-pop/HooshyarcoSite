# هوشیار پاری‌نگر — قالب React سازمانی (Headless WordPress)

قالب React + TypeScript برای **شرکت هوش مصنوعی، نرم‌افزار و طراحی سایت «هوش‌یار پاری‌نگر»** با بک‌اند وردپرس (Headless). فارسی RTL، قابل نصب به‌صورت PWA و آماده خروجی اپلیکیشن اندروید با Capacitor.

> 🔎 **حالت دمو:** فعلاً بدون نیاز به وردپرس، با داده‌ی نمونه کار می‌کند. برای اتصال واقعی، بخش «اتصال به وردپرس» را بخوانید.

---

## ✨ امکانات

### سایت عمومی (متصل به وردپرس)
- صفحه اصلی با Hero انیمیشنی، خدمات، پروژه‌ها، تیم، نظرات مشتریان و سوالات متداول
- صفحات: خدمات (+جزئیات) • پروژه‌ها • تیم • درباره ما • تماس با ما (پیشرفته)
- فروشگاه و محصولات **متصل به ووکامرس** • سبد خرید و پرداخت
- مقالات و آموزش‌ها (متن + ویدیو) از وردپرس
- استخدام + **آزمون آنلاین** با نظارت تصویری، تایمر و تصحیح خودکار
- فرم‌های **گراویتی‌فرم** (تماس، مشاوره، استخدام)
- هدر و فوتر متصل به فهرست/تنظیمات وردپرس، چت آنلاین شناور

### پنل کاربری (مشتری)
- **ورود/ثبت‌نام با شماره موبایل + OTP** (بدون رمز عبور) + محافظ اسپم/قفل حساب
- داشبورد حرفه‌ای با آمار و دسترسی سریع
- **تیکت پشتیبانی** + چت آنلاین • **تمدید پشتیبانی** با پرداخت آنلاین
- **فاکتورها**: مشاهده، دانلود، پرداخت و ارسال لینک فاکتور
- سفارش‌های من (ووکامرس) و اعلان‌ها

### پنل مدیریت (ادمین)
- داشبورد مدیریتی با قیف فروش و شاخص‌های کلیدی
- **CRM** حرفه‌ای: سرنخ‌ها، مشتریان، فرصت‌های فروش، امتیازدهی و اتوماسیون/پیگیری خودکار
- مدیریت تیکت‌ها و پاسخگویی • مدیریت مشتریان
- **حسابداری کوچک فروشگاهی** (ساخت فاکتور، وضعیت پرداخت و درگاه)
- **اطلاع‌رسانی لحظه‌ای به مدیر از طریق ربات بله** + مرکز اعلان‌ها

### یکپارچه‌سازی‌های ایرانی
| سرویس | توضیح |
|---|---|
| 💳 پرداخت | آیدی‌پی، زرین‌پال، نوین‌پی، آقای پرداخت، پی‌پینگ، pay.ir و… |
| 📱 پیامک | ملی‌پیامک، sms.ir، ippanel.co |
| 🤖 اطلاع‌رسانی | ربات **بله** (هشدار لحظه‌ای به مدیر) |
| 🔐 احراز هویت | JWT + ورود با موبایل (OTP) |

### موبایل
- **PWA** قابل نصب با آیکن، حالت تمام‌صفحه و آفلاین (Service Worker)
- **فوتر موبایلی** (تب‌بار اپ‌شکل) + طراحی موبایل‌فرست
- ساختار آماده برای خروجی **اپ اندروید/iOS با Capacitor**

## 🚀 اجرای محلی

```bash
npm install
npm run dev        # توسعه: http://localhost:5173
npm run build      # خروجی production در dist/
npm run preview    # پیش‌نمایش build
```

### ورود به پنل (حالت دمو)
1. از منوی سایت روی «ورود / ثبت‌نام» کلیک کنید.
2. شماره موبایل را وارد کنید — هر شماره‌ای (مثلاً `09123456789`).
3. کد تأیید دمو: **`12345`**
4. برای ورود به پنل مدیریت، تیک «ورود به عنوان مدیر / پشتیبان» را بزنید.

> شماره `09123456789` → نقش مدیر • `09127778899` → پشتیبان • بقیه → مشتری.

## 🔌 اتصال به وردپرس (Headless)

1. افزونه‌های زیر را روی وردپرس نصب کنید:
   - **JWT Authentication for WP REST API** (ورود با توکن)
   - **WooCommerce** + فعال‌سازی REST API
   - **Gravity Forms** + افزونه **Gravity Forms REST API**
   - افزونه سفارشی `hooshyar/v1` (اندپوینت‌های OTP، خدمات، تیم، پروژه، فاکتور و…) — یا از داده‌ی دمو استفاده کنید.

2. فایل `.env` را با آدرس وردپرس پر کنید:

```env
VITE_WP_URL=https://your-site.com
VITE_DEMO_MODE=false
```

3. شناسه فرم‌های گراویتی‌فرم را ست کنید:
```env
VITE_GF_EMPLOYMENT=1
VITE_GF_CONSULTATION=2
VITE_GF_CONTACT=3
```

### مسیرهای API که قالب می‌خواند
| سرویس | مسیر |
|---|---|
| توکن JWT | `POST /wp-json/jwt-auth/v1/token` |
| ووکامرس | `GET /wp-json/wc/v3/products` و `/orders` |
| گراویتی‌فرم | `POST /wp-json/gf/v2/forms/{id}/submissions` |
| محتوای سفارشی | `GET /wp-json/hooshyar/v1/{services,team,projects,faqs,testimonials}` |

> 🔒 **نکته امنیتی:** کلیدهای ووکامرس (consumer_key/secret)، توکن بله و پیامک باید **فقط سمت سرور** (پراکسی/اندپوینت وردپرس) بمانند. در نسخه دمو این فراخوانی‌ها شبیه‌سازی شده‌اند.

## 📱 ساخت اپلیکیشن اختصاصی (Capacitor)

```bash
npm install @capacitor/android @capacitor/ios
npm run build
npx cap add android     # یا ios
npx cap sync
npx cap open android    # ساخت APK در Android Studio
```

## 🗂 ساختار پروژه

```
src/
├── components/        # کامپوننت‌های UI، هدر/فوتر، چت، پنل
├── pages/             # صفحات سایت، پنل کاربری و مدیریت
├── services/          # وردپرس، ووکامرس، پرداخت، پیامک، بله، گراویتی‌فرم
├── store/             # Zustand (auth, cart, tickets, invoices, chat, notifications)
├── mock/              # داده‌های دمو
├── lib/               # ابزارها (اعداد/تاریخ فارسی، قیمت و…)
├── config/            # تنظیمات برند و سرویس‌ها
└── styles/            # استایل سراسری (پوسته تیره پریمیوم)
```
