# Hooshyar Commerce Kit — کیت فروشگاهی هوشیار

افزونه حرفه‌ای ووکامرس با پشتیبانی کامل از **المنتور و المنتور پرو** — سازگار با **ووکامرس ۱۱.۱.۱ به بالا** (PHP 7.4+، وردپرس 6.0+).

تمام استایل‌ها، رنگ‌ها، فونت‌ها، سایزها و چیدمان‌ها هم از **تنظیمات وردپرس** و هم از **کنترل‌های استایل المنتور** قابل مدیریت هستند.

## 📦 نصب

1. فایل افزونه را در `wp-content/plugins/` آپلود و فعال کنید (ووکامرس باید فعال باشد).
2. از منوی **هوشیار کیت ← تنظیمات**، قالب‌ها و یکپارچه‌سازی‌ها را پیکربندی کنید.
3. در المنتور، المان‌ها در دسته **«Hooshyar Kit»** قرار دارند.
4. شورت‌کدها (در صورت عدم استفاده از المنتور):
   - `[hck_cart template="modern" layout="two-column"]`
   - `[hck_checkout template="creative" layout="summary-left"]`
   - `[hck_dashboard template="modern" layout="sidebar-right"]`
   - `[hck_mini_cart]` و `[hck_mobile_nav]`

## ⚙️ تنظیمات کلیدی

### طراحی (Design)
رنگ‌های اصلی/ثانویه/اکسنت، رنگ عنوان و متن، گردی گوشه‌ها، عرض کانتینر و فونت‌های دلخواه (فونت‌های گوگل خودکار بارگذاری می‌شوند). همه این مقادیر به‌صورت CSS Variable روی کل سایت اعمال می‌شوند.

### هدر/فوتر
- قالب: پیش‌فرض / مدرن / مینیمال / خلاقانه
- چیدمان هدر: خطی، وسط‌چین، منوی دوطرفه
- محدوده نمایش: کل سایت / فقط فروشگاه / فقط صفحه اصلی / شناسه صفحات مشخص
- **قالب المنتوری**: با وارد کردن ID یک قالب المنتور (سفارشی یا Theme Builder پرو)، همان قالب داخل ساختار سند نمایش داده می‌شود.

### تلگرام / بله
- توکن ربات و شناسه کانال را وارد کنید (بات بله از `@botfather` در بله ساخته می‌شود).
- قالب پیام با جای‌نگارهای `{title}` `{price}` `{link}` `{sku}` `{categories}` `{excerpt}`
- با دکمه «ارسال پیام آزمایشی» اتصال را بررسی کنید.
- گزارش ارسال‌ها: **هوشیار کیت ← گزارش اعلان‌ها**

### درگاه دیجی‌پی (مستندات: [UPG](https://www.mydigipay.com/developers/docs/upg/#1))
در **ووکامرس ← تنظیمات ← پرداخت‌ها ← DigiPay (UPG)** یا در تنظیمات افزونه:
- محیط: عملیاتی (Live) / آزمایشی (UAT)
- نام کاربری، رمز عبور، Client ID و Client Secret
- ابزار پرداخت ترجیحی: صفحه انتخاب دیجی‌پی / مستقیم کارت / مستقیم کیف پول
- واحد پول فروشگاه: ریال / تومان (در حالت تومان مبلغ ×۱۰ ارسال می‌شود)

جریان پرداخت: `تیکت خرید → redirectUrl → نتیجه POST به callback → تأیید (verify) → تکمیل سفارش` و در استرداد وجه، سرویس `reverse` فراخوانی می‌شود. لاگ کامل در **ووکامرس ← وضعیت ← گزارش‌ها (hck-digipay)**.

## 🧩 المان‌های المنتور

| المان | نام | قابلیت‌ها |
|---|---|---|
| HCK Products | `hck-products` | گرید/کاروسل/اسلایدر/لیست/ماسونری، ۴ قالب کارت، کنترل کامل استایل (کارت، تصویر، عنوان، قیمت، دکمه، ناوبری کاروسل) |
| HCK Banner / Poster | `hck-banner` | ۵ چیدمان، ۷ افکت خلاقانه، اورلی و گرادیان، دو دکمه، کنترل تایپوگرافی کامل |
| HCK Product Banner | `hck-product-banner` | ۴ چیدمان، ۷ افکت، نمایش قیمت/امتیاز/توضیحات، دکمه افزودن به سبد |
| HCK Cart / Checkout / Dashboard | `hck-cart`... | قالب و چیدمان قابل انتخاب + کنترل رنگ و تایپوگرافی |
| HCK User Area Button | `hck-user-area` | دکمه ورود/حساب + منوی کشویی + آیکون سبد با نشان (همگام با ووکامرس) |
| HCK Mobile Nav | `hck-mobile-nav` | نوار ناوبری موبایل با استایل‌های مختلف |

همه المان‌ها از **Group_Control_Typography**، **Border**، **Box Shadow** و کنترل‌های ریسپانسیو استاندارد المنتور پشتیبانی می‌کنند.

## 🗂 ساختار پروژه

```
hooshyar-commerce-kit.php      فایل اصلی افزونه
includes/
  class-hck.php                هسته مرکزی
  class-hck-settings.php       تنظیمات (۱۱ تب)
  class-hck-helpers.php        ابزارهای مشترک، آیکون‌ها، CSS Variable ها
  templates/                   ماژول‌های سبد/صورتحساب/داشبورد/فروشگاه/محصول/هدرفوتر/موبایل‌ناو
  elementor/                   دسته‌بندی، ۸ المان اختصاصی، تمپلیت‌های مشترک
  payments/                    کلاینت API و درگاه دیجی‌پی (UPG)
  social/                      تلگرام، بله، اعلان‌گر محصولات جدید
templates/                     قالب‌های PHP (سبد، صورتحساب، داشبورد، فروشگاه، هدر، فوتر)
assets/css|js|images           استایل‌ها و اسکریپت‌ها
languages/                     ترجمه فارسی (fa_IR) و فایل POT
```

## 🧪 سازگاری

- وردپرس 6.0+
- ووکامرس 8.0 تا 11.1.x (تست‌شده با ۱۱.۱.۱) — سازگار با HPOS
- المنتور 3.5+ و المنتور پرو (ثبت Location های `hck_header` / `hck_footer`)
- RTL به‌صورت کامل (استفاده از CSS Logical Properties + فایل rtl.css)
